Modernizing a legacy security platform

Faraday's vulnerability management platform had grown for a decade with no dedicated design practice. Enterprise security teams depended on it daily, but core workflows were dated and inconsistent.

I joined as the company's UX lead and built the practice from zero: user research, redesigned core workflows, and the design system the whole team builds on. Every feature went through my pipeline of user stories, Mermaid flows, Sketch designs, and Zeplin handoff, so front-end and back-end developers implemented from a single source of truth.

What I know best

HTML, CSS, and JavaScript, built to the standard

I have written front-end code for my whole career, and I design with it in mind. Interfaces I hand off are interfaces I know how to build, and often build myself.

  • Web standards. Semantic, valid HTML and accessible markup (WCAG).
  • Cross-browser compatibility. Tested across browsers and devices, with progressive enhancement so the core works everywhere.
  • Modern CSS. Layout systems, theming, design tokens, and responsive behavior.
  • Vanilla JavaScript. Interaction, state, and performance without leaning on a framework.

This site is hand-coded HTML, CSS, and JavaScript with no framework or build step.
